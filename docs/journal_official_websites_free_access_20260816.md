# 官方期刊官网免费全文采集渠道调研（2026-08-16）

> 目标：为 **NCPSSD 未收录** 的体育核心期刊寻找 **合法免费的官方全文/摘要采集渠道**，
> 避开商业数据库（知网、万方），构建第二个白名单资源通道。
> 本文档记录渠道调研与验证结果，供后续开发采集脚本使用。

---

## 一、背景

NCPSSD（国家哲学社会科学文献中心）虽已打通免登录采集链路，但以下核心期刊 **未收录或收录不全**：

- **体育科学**（中国体育科学学会，核心中的核心）
- **体育学刊**（华南理工/华南师大）
- **上海/成都/广州/沈阳/南京体育学院学报**（部分收录）
- **现代传播、新闻记者、新闻与写作**（新闻传播类，体育传播论文来源）

这些期刊需走 **期刊官网 / 编辑部官网** 等免费渠道补充。

## 二、已成功验证的渠道

### 1. 《体育科学》官网 — ✅ 已验证可免费采集

| 项目 | 详情 |
|---|---|
| 官网 | `http://tykx.xml-journal.net/` |
| 平台 | XML-Journal 期刊采编系统（国内学术期刊常用） |
| 免登录 | ✅ 首页/当期目录/过刊归档/文章详情均免登录 |
| 渲染方式 | 目录页+摘要区**服务端渲染**（requests 可采）；作者/关键词、过刊列表为 **JS 渲染** |
| 全文 | ✅ 提供 **HTML 全文**（`?viewType=HTML`） |
| 摘要 | ✅ 完整中英文摘要（容器 `div.abstract-cn` / `abstract-en`，requests 已实测） |
| 验证文章 | 《新时代我国体育发展战略研究的框架和方向》DOI `10.16469/J.css.2026KX045` |

> **字段可得性（实测）**：requests 可直接抓 **标题 + 中英文摘要**（核心需求已满足）；
> 作者/关键词/基金为 **Vue 数据绑定**（`<ul class="article-keyword">`），需 Playwright 或解析内嵌 JSON。

**已验证的链接结构：**

| 类型 | URL 模式 |
|---|---|
| 首页 | `http://tykx.xml-journal.net/` |
| 当期目录 | `/cn/article/current` |
| 过刊归档 | `/archive_list`（**JS 渲染**，数据经 `getArchiveData` AJAX 异步加载） |
| 文章详情 | `/article/doi/10.16469/J.css.2026KX045` |
| 全文 HTML | `/article/doi/10.16469/J.css.2026KX045?viewType=HTML` |

> ⚠️ **渲染方式分层**：当期目录 `/cn/article/current` 与文章详情为**服务端渲染**（requests 可采）；
> 过刊列表 `/archive_list` 为 **JS 渲染**（数据在 `archive_list.js` 的 `getArchiveData` 异步获取），
> 需 Playwright 或逆向其 AJAX 端点。采集脚本需按此分策略处理。

**文章条目 HTML 特征**：`<a>文章标题</a>` + `<a>摘要</a>` + `<a>HTML全文</a>` 并列，
每篇带 DOI，摘要容器 class 为 `abstract-cn`（中文）、`abstract-en`（英文，待验证）。

### 2. 《体育学刊》官网 — ✅ 已打通「期刊全文」栏目（2026-08-17 新增验证）

> **更新（2026-08-17）**：此前判定"仅目次无全文"已过时。官网新增 **"期刊全文"栏目 `/book/`**，
> 提供 **2007 年至今全部过刊目录 + 文章详情（完整中英文摘要/作者/关键词/PDF全文）**。

| 项目 | 详情 |
|---|---|
| 官网 | `https://tyxk.scnu.edu.cn/` |
| 过刊总目录 | `https://tyxk.scnu.edu.cn/book/`（含 2007-2026 各年份、各期 URL） |
| 期次目录 | `/book/{year}nian/di{issue}qi/`（如 2026 第1期 `di1qi`，部分期带下划线如 `di3qi_`，需从总目录动态发现） |
| 文章卡片 | `<h5.card-title><a href="/a/日期/编号.html">`，标题+详情URL |
| 文章详情 | `/a/{YYYYMMDD}/{id}.html`：**中英文标题、作者及单位、中英文摘要、关键词、分类号、文章编号、PDF链接** |
| PDF 全文 | `https://statics.scnu.edu.cn/pics/...pdf`（协议相对 `//statics...`，免费下载，实测 736KB） |

| 编码 | 响应头无 charset，requests 误判 ISO-8859-1，需用 `apparent_encoding`（UTF-8）解码 |
| 采集脚本 | `scripts/fetch_tykx_scnu.py`（已开发，Adapter 模式可复用） |
| 成果 | 2019-2026 扫描全量，**体育新闻/传播相关文献约 51+ 篇**（标题+摘要关键词筛选） |

> ⚠️ 注：详情页无独立 DOI，但含"文章编号"（如 `1006-7116(2026)01-0064-11`，含 ISSN+年卷期页码）。
> 采集方法可复用到其他 scnu 系/同类高校学报官网。

## 四、渠道可行性结论

1. **XML-Journal / scnu 学报 / chinajournal / cbpt 类采编平台** 是国内学术期刊主流的免费官网平台，
   有的开放完整摘要+全文（如体育学刊、体育科学），有的被验证码/登录限制（如 cbpt 详情页）。
2. **采集成本低**：服务端渲染的用 `requests + BeautifulSoup` 即可，速度快于 NCPSSD 的 Playwright。
3. **数据更完整**：开放渠道通常含完整摘要 + 关键词 + PDF，比 NCPSSD 的摘要更丰富。
4. **合规性**：期刊官网免费全文属编辑部公开发布内容，符合「白名单」免费采集原则。
5. **新闻传播类期刊（现代传播/新闻记者/新闻与写作）免费官网渠道有限**，其文章主要在知网与微信公众号，
   建议以微信公众号（需人工/专门采集）或知网题录为补充，不纳入官网直采。
